# Changelog

Principais atualizações e correções do sistema.

## [Versão Recente]

### Corrigido
*   **Clean Forms**: Removido todo e qualquer dado fictício (mock data) da inicialização do formulário de cadastro de profissionais.
*   **Placeholders**: Ajuste geral em todos os inputs do formulário para reduzir confusão visual, alterando placeholders que simulavam dados reais por instruções de preenchimento.
*   **Gestão de Documentos**:
    *   Refatorado para iniciar com lista vazia.
    *   Adicionada trava de integridade: campo 'Tipo de Documento' bloqueado após upload de arquivo.
*   **Interface**: Refinamentos gerais na estilização dos formulários para melhor usabilidade e experiência do usuário.
